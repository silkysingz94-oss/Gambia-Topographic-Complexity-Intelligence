DATA SOURCES & METHOD
Administrative data: Census_EAs_Geo.json, Urban-Planning-Intelligence GitHub repository.
Elevation: AWS public Terrarium elevation tiles (SRTM-derived terrain).
Wavelet: scale-normalised Laplacian-of-Gaussian approximation to the Mexican-hat CWT.
Complexity: mean absolute CWT response across selected scales.
Dominant wavelength: 2πσ for the scale with the largest absolute response.
